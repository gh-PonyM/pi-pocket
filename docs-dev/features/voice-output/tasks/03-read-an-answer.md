# 03: Read aloud under an answer

**What to build:** a person taps **Read aloud** under any answer of Pi and hears that answer,
as the words of task 02. The tap works whether voice output is off or on: with it off, the
answer is read and a notice says that voice output is off and how to turn it on. The reading
uses the owner's voice and speed. Read aloud replaces what plays, and an answer with code
follows the page's code switch.

**Blocked by:** 02.

**Status:** ready

- [ ] Read aloud shows under each finished answer, next to the app's own actions, and reads that answer alone.
- [ ] With the voice off, the answer is read and a notice says how to turn voice output on.
- [ ] The words that play have no Markdown in them, and the rate and voice are the settings'.
- [ ] A browser test records what plays after a tap.
